# NT Multi Character

**Cinematic Character Selection | QBCore · Qbox** · by [NT Development](https://ntdevs.com)

> This repository is a showcase. The resource itself is delivered through Tebex / Cfx.re Asset Escrow after purchase.

![NT Multi Character](https://dunb17ur4ymx4.cloudfront.net/packages/images/04cdaa2c65024f2081d3e557050f254765ff5654.jpeg)

A character selection unlike the usual ones, with a cinematic camera, music player and arrival scene.

## Preview
[![Preview video](https://img.youtube.com/vi/aTgYdz70Sd8/maxresdefault.jpg)](https://www.youtube.com/watch?v=aTgYdz70Sd8)

## Features
- Character selection: theme, filter, camera and animation per player
- Identity creation and spawn selector
- Arrival camera with film bars and a title card
- Anti abuse: no logout while jailed, cuffed or dead
- Works with 7 clothing resources
- Languages: English, Turkish, French
